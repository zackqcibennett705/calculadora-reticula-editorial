## Overview

Calculadora de Reticula Editorial permite estudiar la construccion de una reticula editorial utilizando dimensiones reales. Desde la interfaz puedes elegir el formato de papel, establecer margenes, definir columnas y modificar el intercolumnado para comprobar inmediatamente su efecto sobre la composicion y el ritmo visual de una pagina.

Esta herramienta esta dirigida a estudiantes y docentes de diseno editorial, asi como a quienes necesitan una consulta practica al preparar maquetas o documentos para impresion. Su orientacion didactica conecta los conceptos de reticula con procesos habituales de Adobe InDesign, incluidas las conversiones y equivalencias del sistema tipografico.

---

## Funcionalidades principales

- Representacion y calculo instantaneo de reticulas editoriales.
- Seleccion de formatos de papel mediante presets o introduccion de medidas propias.
- Controles para margenes, columnas, medianiles y reticula base.
- Canvas interactivo con capas cuya visibilidad puede alternarse.
- Conversion entre los sistemas tipograficos PostScript/DTP y Didot.
- Explicaciones de apoyo para interpretar los distintos parametros.
- Equivalencias pensadas para facilitar el trabajo en InDesign.
- Experiencia de una sola pagina, sin interrupciones entre las distintas acciones.

## Como usarla

1. Elige uno de los formatos disponibles o introduce manualmente el tamano del papel.
2. Define los margenes, la cantidad de columnas, los medianiles y la reticula base.
3. Revisa el canvas mientras ajustas los valores para analizar la distribucion de la pagina.
4. Activa o desactiva las capas para contrastar distintas estructuras y comprobar proporciones.
5. Consulta las conversiones tipograficas al alternar entre PostScript/DTP y Didot.
6. Utiliza las medidas resultantes como referencia para organizar maquetas y documentos en un flujo parecido al de InDesign.

## Personalizacion

Al tratarse de una aplicacion web de una sola pagina, los ajustes basicos se realizan directamente desde los controles de la interfaz. No es necesario configurar un archivo complejo para comenzar a utilizarla.

Si vas a adaptar el proyecto, consulta el HTML principal y los scripts relacionados para modificar aspectos como:

- presets de formatos
- valores iniciales de los margenes
- conversiones del sistema tipografico
- capas visibles del canvas
- mensajes de ayuda y equivalencias
